# 南意秋棠 · 微信小程序发布上架指南

本文说明从小程序注册到提审发布的完整步骤，以及与后端待办的依赖关系。  
**仅改客户端无法完成微信一键登录**；正式上架前请对照文末检查表。

---

## 一、注册 / 认证小程序并获取 AppID

1. 使用企业主体（推荐）打开 [微信公众平台](https://mp.weixin.qq.com/) → 注册小程序。
2. 完成主体认证（对公打款等），否则部分能力与类目受限。
3. 进入「开发管理 → 开发设置」，复制 **AppID（小程序 ID）**；有需要再配置 AppSecret（仅后端保管，勿写入小程序代码）。
4. 若需与公众号/App 打通同一用户，去 [微信开放平台](https://open.weixin.qq.com/) 绑定同一主体下的小程序，以便后端拿到 `unionid`。

---

## 二、替换 `project.config.json` 中的 AppID

当前工程使用占位：

```json
"appid": "touristappid"
```

**不要编造正式 AppID。** 拿到真实 ID 后：

1. 用微信开发者工具打开 `nanyi-qiutang-mp/`。
2. 修改 `project.config.json` 的 `appid` 为正式值，或在工具「详情 → 基本信息」中绑定。
3. 确认 `description` 中占位提示可删除或改为正式说明。
4. 替换后重新编译；真机调试前须已配置服务器合法域名（见第三节）。

检查项：

- [ ] `appid` 不再是 `touristappid`
- [ ] 开发者工具能预览，无「AppID 无效」报错
- [ ] 团队成员 AppID 权限已添加

## 三、服务器域名配置

微信公众平台 → 开发管理 → 开发设置 → **服务器域名**：

| 类型 | 必须配置的域名 |
| --- | --- |
| request 合法域名 | `https://products.nanyiqiutang.cn` |
| uploadFile 合法域名 | `https://products.nanyiqiutang.cn` |
| downloadFile 合法域名 | `https://products.nanyiqiutang.cn` |

说明：

- 协议必须是 **https**；不带路径、不带端口。
- `downloadFile` 用于试穿结果「保存到相册」与分享卡片拉图，**不可省略**。
- 本地调试可勾选「不校验合法域名」；**提审包必须校验通过**。
- 若联调环境用 `utils/config.js` 的 `ENV='dev'`，勿将内网域名提交审核；默认应保持 `ENV='prod'`。

## 四、隐私协议 / 用户协议 / 类目 / 备案

中国大陆提审常见要求（需**产品/法务准备材料**，代码库未内置完整协议页）：

1. **用户隐私保护指引**  
   - 在公众平台填写：收集的信息类型（如：手机号用于账号；相册/相机用于 AI 试穿；剪贴板用于复制客服微信等）。  
   - 说明用途与是否与第三方共享。  
   - 小程序内需提供可访问的隐私政策入口（可用 web-view 外链或静态页）。

2. **用户服务协议**  
   - 账号注册、内容规范、试穿结果免责等条款。

3. **服务类目**  
   - 按实际业务选择（例如服饰箱包 / 服装配件 / 信息查询等），类目与页面能力需匹配，否则易驳回。

4. **ICP / 小程序备案**  
   - 按当地与微信当期政策完成备案；页脚已展示 `浙ICP备2024081979号`，以工信部/管局登记为准。

5. **权限申请说明**（开发者工具「本地设置 / 隐私」）  
   - 相册写入、相机、用户信息等需在代码与后台声明一致。

> 客服微信号以运营确认为准（当前配置见 `utils/config.js` 的 `contacts`；设计稿曾有拼写变体，勿擅自改号）。

## 五、开发者工具：预览 → 体验版 → 提交审核 → 发布

1. **开发预览**  
   - 导入本目录 → 编译 → 预览二维码，真机扫码验证：首页列表、筛选、详情、点赞、评价、试穿、登录。

2. **上传代码**  
   - 「上传」填写版本号与备注（建议备注关联本次改动：手机号注册、点赞评价等）。

3. **设为体验版**  
   - 公众平台 → 管理 → 版本管理 → 将刚上传的开发版本设为体验版，发给内部验收。

4. **提交审核**  
   - 填写功能页面路径（至少：首页、详情、试穿、我的、登录）。  
   - 说明测试账号（若审核员需登录：提供手机号测试号）。  
   - 若微信登录仍未开通，在审核说明中写明：「微信一键登录依赖后端接口尚未上线，可用手机号登录完成主流程」。

5. **审核通过后发布**  
   - 正式发布上线；可配置灰度（百分比放量）。

## 六、审核常见驳回点

| 驳回点 | 应对 |
| --- | --- |
| 登录不可用 / 无测试号 | 提供可用的手机号测试账号；说明微信登录待后端开通 |
| 隐私协议缺失或不符 | 补齐隐私指引与弹窗；声明相册/相机用途 |
| 类目不符 | 调整类目或隐藏无关能力 |
| 内容不完善 / 空页面 | 评价、点赞、客服需可点通；避免空转入口 |
| 诱导分享 / 过度营销 | 分享文案克制，勿强制分享 |
| 域名未配置 | 确认三类合法域名已生效 |
| AppID 为体验/占位 | 必须使用正式认证主体 AppID |

## 七、与后端待办的依赖（小程序无法单独完成）

| 依赖项 | 状态 | 说明 |

| 试穿 status 的 query token | **保持现状** | 后端只认 query，客户端未改 Header |

## 九、本地联调提示

```js
// utils/config.js
const ENV = 'prod'; // 默认生产；仅本地可改为 'dev'
```

- `dev` 默认指向 `http://127.0.0.1:5000/api`，需开发者工具关闭域名校验。  
- **禁止**对生产环境做写压测（试穿任务、评价刷量等）。
