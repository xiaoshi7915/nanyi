# 如何查看任务和生成的图片

## 1. 查看数据库中的任务

### 方法一：通过 SQL 查询
```bash
# 连接到数据库（请使用.env中的实际配置）
mysql -h $DB_HOST -u $DB_USER -p'$DB_PASSWORD' $DB_NAME

# 查看所有任务
SELECT id, status, model_type, shot_type, created_at, result_image_url, local_path 
FROM tasks 
ORDER BY created_at DESC 
LIMIT 10;

# 查看特定任务
SELECT * FROM tasks WHERE id = '你的任务ID';

# 查看已完成的任务
SELECT id, status, result_image_url, local_path, created_at 
FROM tasks 
WHERE status = 'completed' 
ORDER BY created_at DESC;
```

### 方法二：通过 API 查询
```bash
# 查询任务状态
curl http://121.36.205.70:15001/api/v1/try-on/status/你的任务ID

# 示例
curl http://121.36.205.70:15001/api/v1/try-on/status/727d1814-93e8-4061-8a03-d5cafd6432ed
```

## 2. 查看生成的图片

### 方法一：查看本地存储
生成的图片保存在以下目录：
```bash
# 本地存储路径
cd /opt/try_on/backend/storage/generated

# 列出所有生成的图片
ls -lh /opt/try_on/backend/storage/generated/

# 查看最新生成的图片
ls -lt /opt/try_on/backend/storage/generated/ | head -10
```

### 方法二：通过 OSS URL 访问
如果任务状态为 `completed`，可以通过 `result_image_url` 字段中的 OSS URL 直接访问图片：

```bash
# 从数据库获取 OSS URL（请使用.env中的实际配置）
mysql -h $DB_HOST -u $DB_USER -p'$DB_PASSWORD' $DB_NAME \
  -e "SELECT id, result_image_url FROM tasks WHERE status='completed' ORDER BY created_at DESC LIMIT 5;"
```

OSS URL 格式示例：
```
https://testflink123.oss-cn-hangzhou.aliyuncs.com/generated/2026/01/23/xxx.jpg
```

### 方法三：通过 API 响应查看
调用任务状态查询 API，响应中会包含：
- `result_image_url`: OSS 图片 URL（可直接访问）
- `local_path`: 本地文件路径

```json
{
  "task_id": "727d1814-93e8-4061-8a03-d5cafd6432ed",
  "status": "completed",
  "result_image_url": "https://testflink123.oss-cn-hangzhou.aliyuncs.com/generated/2026/01/23/xxx.jpg",
  "local_path": "/opt/try_on/backend/storage/generated/xxx.jpg"
}
```

## 3. 任务状态说明

- `pending`: 等待处理
- `processing`: 正在处理中
- `completed`: 已完成（可以查看图片）
- `failed`: 处理失败（查看 error_message 了解原因）

## 4. 快速查看脚本

创建查看脚本：
```bash
# 查看最近的任务
cd /opt/try_on/backend
python3 -c "
from app.services.db_service import db_service
tasks = db_service.list_tasks(limit=5)
for task in tasks:
    print(f\"任务ID: {task['task_id']}\")
    print(f\"状态: {task['status']}\")
    print(f\"创建时间: {task['created_at']}\")
    if task['result_image_url']:
        print(f\"图片URL: {task['result_image_url']}\")
    if task['local_path']:
        print(f\"本地路径: {task['local_path']}\")
    print('---')
"
```
